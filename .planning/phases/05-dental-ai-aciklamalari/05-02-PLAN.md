`export async function POST(req: NextRequest)`:
1. `const { userId } = await auth()` → 401 `{ error: 'Unauthorized' }` if absent.
2. Parse body `{ term, category }` (catch → {}). Validate:
   - `term` is non-empty string after trim → else 422 `{ error: 'Terim zorunludur.' }`.
   - `category` ∈ {'medication','disease','allergy'} → else 422 `{ error: 'Geçersiz kategori.' }`.
3. `const term_key = normalizeTerm(term)`.
4. CACHE READ: `supabaseAdmin.from('dental_descriptions').select('display_term, category, dental_impact, risk_level, precaution, active_ingredient').eq('user_id', userId).eq('term_key', term_key).eq('category', category).maybeSingle()`. If a row exists → build the DentalDescription from it, append disclaimer (step 7), return 200 (cache hit — no model call).
5. CACHE MISS: call `generateDentalDescription(term.trim(), category)`. On `DentalDescriptionError` → `console.error('[descriptions POST]', { code, message })` and return 502 `{ error: 'Açıklama üretilemedi.' }` (mirror anamnesis 502).
6. CACHE WRITE: upsert into dental_descriptions with `{ user_id: userId, term_key, category, display_term: term.trim(), dental_impact, risk_level, precaution, active_ingredient }`, `onConflict: 'user_id,term_key,category'`. A write failure is non-fatal — log and continue (still return the generated description); do NOT 500 the user over a cache miss-write.
7. DISCLAIMER (DESC-06): build the response object and set `disclaimer: 'Bu bilgi klinik karar desteği değildir'` as a literal string constant in this file — appended server-side, NEVER from the model. Return 200 with the full `DentalDescription` (display_term, category, 3 fields, active_ingredient, disclaimer).

Define the disclaimer once: `const DISCLAIMER = 'Bu bilgi klinik karar desteği değildir' as const` and use it on BOTH the cache-hit and cache-miss return paths so it can never be omitted.
