`src/app/api/templates/route.ts`:
- `GET`: list templates for user. Select `id, name, department, current_version, updated_at` from `form_templates` where `user_id` and `is_archived = false`, plus a count of `template_questions`. Return `TemplateListItem[]` (compute `question_count`). Order by `updated_at` desc.
- `POST`: body `CreateTemplateBody`. Validate `name` non-empty (422 'Şablon adı zorunludur.'), `department` ∈ VALID_DEPARTMENTS (422 'Geçersiz bölüm.'). Insert `{ user_id, name, department }`. Return created `TemplateListItem` (question_count 0) status 201.

`src/app/api/templates/[id]/route.ts` (RouteContext `{ params: Promise<{ id: string }> }`):
- `GET`: return the template header + its `template_questions` ordered by `position`. 404 if not owned.
- `PATCH`: body `{ name?, department? }`. Update header, set `updated_at = now()`. 422 on invalid department. 404 if not owned.
- `DELETE`: soft-delete — set `is_archived = true` (do NOT hard delete; template_versions rows referenced by sessions must survive). 404 if not owned.

`src/app/api/templates/[id]/questions/route.ts`:
- `GET`: questions for template ordered by position (404 if template not owned).
- `POST`: body `UpsertQuestionBody`. Validate `prompt` non-empty, `question_type` ∈ VALID_QUESTION_TYPES, and if `question_type === 'multi_select'` then `options` must be a non-empty string[] (422 'Çoklu seçim için en az bir seçenek gerekir.'). Assign `position` = current max(position)+1 for this template (0 if none). Insert with `user_id`. Catch 23505 on (template_id, position) → retry once with recomputed position, else 409. Return created `TemplateQuestionRow` 201.
- `PATCH` (reorder): body `{ order: string[] }` = array of question ids in new order. In a single pass, update each question's `position` to its index in the array. To avoid the (template_id, position) UNIQUE collision during reorder, first offset all affected rows' position by +1000 (write phase 1), then set final positions (write phase 2). Validate all ids belong to the template (422 otherwise). Return updated `TemplateQuestionRow[]`.

`src/app/api/templates/[id]/questions/[questionId]/route.ts` (params `{ id, questionId }`):
- `PATCH`: body `UpsertQuestionBody` (partial). Update prompt/question_type/options. Re-validate multi_select options rule. 404 if not owned.
- `DELETE`: delete the question. 404 if not owned. (Deleting from the DRAFT working set is fine — published versions snapshot independently.)

Create `src/app/api/templates/[id]/publish/route.ts`. Admin-gated (`getRole() === 'superadmin'`), ownership-checked.

`POST`:
1. Load the template header (404 if not owned) and all its `template_questions` ordered by position.
2. Reject 422 'Yayınlamak için en az bir soru ekleyin.' if the template has zero questions.
3. Compute `nextVersion = template.current_version + 1`.
4. Build the snapshot: map each question row to `SnapshotQuestion` `{ id, prompt, question_type, options, position, required }`.
5. Insert into `template_versions`: `{ user_id, template_id: id, version: nextVersion, name: template.name, department: template.department, questions: <SnapshotQuestion[]> }`. The `questions` jsonb is the FROZEN copy — sessions reference this row, never the live template_questions.
6. On success, `UPDATE form_templates SET current_version = nextVersion, updated_at = now()` for this template.
7. Catch 23505 on (template_id, version) UNIQUE → 409 'Bu sürüm zaten yayınlanmış.' (concurrent publish guard).
8. Return `{ version: nextVersion, template_version_id: <inserted id>, question_count }` status 201.

Do NOT update or delete any prior template_versions row — immutability is the whole point of TPLT-04.
  </action>
