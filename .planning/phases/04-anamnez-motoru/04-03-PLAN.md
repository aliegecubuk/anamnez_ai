<feature>
  <name>Transcript → structured anamnesis answers with confidence</name>
  <files>src/lib/anamnesis/schema.ts, src/lib/anamnesis/mapper.ts, src/lib/openai/anamnesis.ts</files>
  <behavior>
buildAnswerSchema(questions: SnapshotQuestion[]):
  - yes_no → boolean property; text → string; numeric → number; multi_select → array of enum (from question.options).
  - each answer object also carries a `confidence` number (0..1).
  - returns a strict JSON schema with one entry per question keyed by question.id, plus a top-level `corrected_transcript` string.

normalizeAnswers(raw, questions):
  - coerces each raw answer_value to its question_type (string→number for numeric; truthy→bool for yes_no; filters multi_select values to those in options).
  - clamps confidence to [0,1]; missing/unparseable → answer_value null, confidence 0.

buildMissingAlerts(answers, questions): returns MissingFieldAlert[] for every REQUIRED question whose answer_value is null/empty (ANAM-04 support, consumed by 04-04).

mapTranscriptToAnswers(transcript, questions): calls GPT-4o, returns AiMappingResult.
  </behavior>
  <implementation>See tasks below — strict RED→GREEN per file.</implementation>
</feature>
