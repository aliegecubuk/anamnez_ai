```sql
-- Phase 3: Ses Boru Hattı (STT pipeline)
-- Adds: transcript_segments (append-only per-chunk transcripts)
-- Modifies: sessions.audio_format, sessions.recorder_state
-- All rows user-scoped via Clerk JWT 'sub' claim (pivot template — defense-in-depth)
-- App-layer isolation: routes use supabaseAdmin + .eq('user_id', userId) per pivot pattern.

-- ============================================================
-- sessions: forward-compatible columns for STT
-- ============================================================
ALTER TABLE public.sessions
  ADD COLUMN audio_format text
    CHECK (audio_format IS NULL OR audio_format IN (
      'audio/webm;codecs=opus',
      'audio/webm',
      'audio/mp4',
      'audio/mp4;codecs=mp4a.40.2',
      'audio/mpeg',
      'audio/wav'
    ));

ALTER TABLE public.sessions
  ADD COLUMN recorder_state text NOT NULL DEFAULT 'idle'
    CHECK (recorder_state IN ('idle', 'recording', 'paused', 'stopped', 'completed'));

-- ============================================================
-- transcript_segments: append-only per-chunk Whisper output
-- ============================================================
-- Each row = one Whisper API result for one ~5s audio chunk.
-- sequence: monotonic integer per session (0, 1, 2, ...) — client assigns, DB enforces uniqueness.
-- content:  Turkish text returned by Whisper (may be empty string for silence).
-- started_at / ended_at: client-reported wall-clock timestamps for the chunk window (used for replay UX).
-- created_at: server-side insertion time (used for "server received" audit + SSE ordering tie-break).
CREATE TABLE public.transcript_segments (
  id          uuid        PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     text        NOT NULL,
  session_id  uuid        NOT NULL REFERENCES public.sessions(id) ON DELETE CASCADE,
  sequence    integer     NOT NULL CHECK (sequence >= 0),
  content     text        NOT NULL,
  started_at  timestamptz NOT NULL,
  ended_at    timestamptz NOT NULL,
  created_at  timestamptz NOT NULL DEFAULT now()
);

ALTER TABLE public.transcript_segments ENABLE ROW LEVEL SECURITY;

CREATE POLICY "user_isolation" ON public.transcript_segments
  FOR ALL
  USING      (user_id = auth.jwt() ->> 'sub')
  WITH CHECK (user_id = auth.jwt() ->> 'sub');

CREATE INDEX transcript_segments_user_id_idx     ON public.transcript_segments (user_id);
CREATE INDEX transcript_segments_session_seq_idx ON public.transcript_segments (session_id, sequence);
CREATE INDEX transcript_segments_session_created_idx
  ON public.transcript_segments (session_id, created_at);

-- One sequence number per session — guards against duplicate chunk submissions on retry.
-- Plan 03-02 catches the resulting 23505 error and returns 200 idempotently.
CREATE UNIQUE INDEX transcript_segments_session_seq_unique
  ON public.transcript_segments (session_id, sequence);
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App-layer user_id filter | PRIMARY: every STT route must `.eq('user_id', userId)` before any DB op (per pivot pattern in /api/patients) |
| Supabase RLS | Defense-in-depth: even if a route forgets the filter, RLS user_isolation blocks cross-user reads when JWT bridge is on. Currently OFF in test mode but policies remain. |
| audio_format CHECK | DB rejects unknown mimetypes — guards against malicious codec strings reaching Whisper |
| recorder_state CHECK | DB rejects invalid state strings — server-side enum enforcement |
| Migration execution | Schema changes only via service_role (migration runner) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01-01 | Information Disclosure | transcript_segments.content (PII — patient symptoms, names voiced by dentist) | mitigate | App-layer .eq('user_id', userId) filter on every read; RLS user_isolation policy (defense-in-depth); service_role used only in server route handlers (never client-exposed) |
| T-03-01-02 | Tampering | duplicate sequence on retry | mitigate | UNIQUE(session_id, sequence) — second insert with same sequence raises 23505; Plan 03-02 catches it and returns 200 idempotently rather than 5xx |
| T-03-01-03 | Tampering | invalid audio_format string | mitigate | CHECK constraint on sessions.audio_format restricts to known whitelist; rejects malformed strings before they reach Whisper |
| T-03-01-04 | Tampering | invalid recorder_state string | mitigate | CHECK constraint on sessions.recorder_state restricts to FSM-valid values; rejects arbitrary strings from compromised clients |
| T-03-01-05 | Elevation of Privilege | cross-user transcript read via direct UUID guess | mitigate | Plan 03-02's chunk upload + SSE routes both call `.eq('user_id', userId)` after fetching userId from Clerk auth(); UUIDv4 also makes guessing infeasible at ASVS L1 |
| T-03-01-06 | Information Disclosure | leaked audio bytes | accept | Audio bytes never persisted (ephemeral chunk handling per Plan 03-02); KVKK least-data principle satisfied; if retention later required, follow-up phase adds Supabase Storage |
